# 面向可靠图像编辑的诊断式评价方法研究

## 候选创新全景与导师讨论方案

讨论对象：黄天志 huangtianzhi（htz）与指导教师。整理日期：2026 年 10 月 28 日。

本文整理此前讨论的全部 28 个候选方向，提出建议主线、开源复用方案、贡献边界和验证计划。它是研究提案，不是已完成实验的成果报告。创新性等级与可行性是规划判断，不代表已经查明首创，也不代表论文录用概率。本轮核实了若干官方开源页面；未下载运行模型，未完成全领域查新。文献已有能力、候选新增贡献和待验证假设分别说明。

## 一 建议带给导师的核心观点

研究问题：当图像编辑产生可疑变化时，评价器能否获取有辨别力的证据，区分合理关联变化与非预期损伤，并形成能够被后续证据验证或推翻的诊断？

建议主方法：学习诊断成立、撤销与保持的条件，用这些条件指导证据获取和诊断更新。方法包含相互连接的两项研究任务：可检验诊断学习，以及面向当前疑点的主动核验。合理变化判断是重要问题场景；修复反馈和辅助小组决策是应用验证。

主线流程：原图与指令及结果 → 建立编辑要求和当前疑点 → 提出候选解释 → 选择必要检查 → 更新诊断或保留不确定性 → 输出问题证据及纠错保护条件。

例如，衣服改蓝后文字损坏：恢复文字但保留蓝色应撤销文字损伤；美化背景不应撤销；恢复文字同时改回颜色应撤销旧诊断并报告任务失败。对于玻璃材质、阴影、遮挡等问题，必须进一步区分合理关联变化与真实损伤，不能把所有差异视作错误。

预期贡献应体现为具体的表示、监督与学习机制，以及真实数据上的独立验证；不能把“反事实”“智能体”“多工具”作为创新本身。

## 三 最终建议主路线

保留所有方向作为研究地图，但第一版方法集中于 7、8、9、13、22，以 3 为关键挑战场景，以 20、26、27 为验证支柱。第 13 项先在有限检查集合上研究，避免无限工具智能体。第 16 项先实现简洁输出，不承诺另外训练完整反馈系统。

### 可检验诊断学习

输入为原图、指令、编辑结果和当前证据；每条诊断记录对象或区域、违反的要求、证据、状态与不确定性。额外学习诊断对受控变化应有的响应。自由文本可以由冻结模型表达，但核心结论必须对应可核验字段。

训练采用真实性监督、对应修正后的诊断撤销约束、无关变化下的保持约束、新损伤识别约束。不能只训练一致性，否则“永远没有错误”也可能稳定。需要独立真值锚定。损失形式和权重由开发集实验确定，不预先假定特定公式有效。

首选冻结基础视觉或多模态模型，缓存特征，训练轻量诊断头；若信息在特征中不可分，再考虑参数高效适配。小头不代表推理系统便宜，冻结骨干的显存、预处理和调用时间均需统计。

### 面向疑点的主动核验

初始检查集合限制为少量有明确语义的操作：原图与结果对应区域放大、文字识别比对、区域或边界核查、一次固定形式的局部视觉问答。工具可以按需删减，不要求全部常驻。

状态包括当前疑点、已有证据及剩余预算。学习选择下一个检查，并在检查后更新诊断。训练阶段可对多个候选检查进行离线枚举，以独立诊断标签计算损失降低及成本；推理时只能预测收益，不能使用正确标签。置信度提升或模型自称“有帮助”不能单独作为奖励。

先用监督排序或回归学习检查价值，必要时再升级为序贯学习。离线缓存所有检查用于研究不意味着部署时免费：成本按实际被选择的操作累计。若全量检查本身便宜，应允许它成为强基线，不能人为制造主动策略的优势。

### 应用验证

将诊断状态提供给小组决策器；或独立固定一个编辑工具与执行次数，验证纠错条件。诊断真实性与修复有效性分别评价。真实工具修不好不直接否定诊断；自家评分提高也不能证明修复有效。

## 四 开源复用与已有研究边界

以下“可复用”指官方页面提供实现或下载入口，尚未做本地安装和权重完整性验证。“成熟”仅指相应基础能力有可用实现，不代表在本项目任务上已经足够准确。使用前需固定版本、检查代码与权重及数据的许可和访问条件，并运行小规模验收。

| 组件或研究 | 本轮核查状态 | 可以承担的工作 | 仍需验证或研究的部分 |
|---|---|---|---|
| EditScore [1] | 官方仓库可访问，提供评分模型、权重与数据入口及训练配置 | 通用编辑质量基线、冻结评分器、候选结果排序基线 | 不应把分数视为诊断真值；诊断响应和局部证据可靠性要另外测 |
| RewardHarness [2] | 官方项目链接到可访问代码，提供路由、工具技能库与演化流程 | 主动评价的重要相关基线，可参考路由与缓存组织 | 开源代码不等于全本地；需核查 API 依赖。工具部分包含上下文过程描述，不应等同于实际外部传感工具 |
| SpatialReward [3] | 论文可访问；论文所指 Kwai-Keye/SpatialReward 地址本次返回 404 | 空间定位评价的文献对照 | 尚不能据此列为已可复现。勿与同名文本生成图像空间评分仓库混淆 |

| PaddleOCR [6] | 官方工具、模型入口与部署说明可访问 | 文字区域与识别结果 | 原图识别失败不能被误解释为结果改变；需要低可读性状态及人工抽查 |
| 裁剪 颜色与几何差异 | 可由普通图像库确定性实现，不必额外训练大模型 | 低成本证据、简单强基线 | 像素差异不能代表损伤，需考虑对齐与指令 |

本轮未给通用多模态骨干指定“最强”型号：应结合实验室显存、许可、已有部署和同一验证集选择。可以从已复用评价模型的骨干出发，避免同时引入多个大模型。

### 哪些已有能力应当承认

区域定位、多维评分、工具选择、生成解释、固定编辑器上的反馈修复，都有相关工作。不能将这些能力本身写成首创。SpatialReward 已研究空间证据评价；RewardHarness 已研究按任务路由工具技能及库更新。[2][3]

此前查新还涉及 R³-Refiner、ImageDoctor、ReasonEdit 等，相关材料保留在同目录 htz_diagnostic_evaluator_novelty_review_20261027.md。该旧报告需要在正式提交前再核实版本与实现，尤其不能把“反馈有修复收益”或“跨编辑器迁移”直接宣称首次。本轮没有重新复核这些论文全部细节。

### 哪些能力尚不能假定已经足够

本项目需要的组合性质是：真实性正确；对应修正时撤销；无关变化时保持；合理关联变化不误罚；检查能提高正确性；工具失败时保留不确定性。目前查阅的基础组件说明不能替代这些实验，也不足以证明所有已有评价器都失败。应先测强基线，确认真实缺口，再决定哪一项值得自研。

特别是对 RewardHarness 的区分必须落在可测机制上：以诊断假设及其响应条件为状态，学习逐次证据的边际诊断收益。仅把库路由改称“主动诊断”不构成差异；若强基线已覆盖相同机制，应据实验调整贡献主张。

## 五 鲁棒性不要求实现全部想法

模块越多，可能同时增加错误传播、调用成本和不可解释的交互。鲁棒性应由故障覆盖、明确的不确定状态和独立压力测试建立。先列风险，再为每类风险配置最低必要能力；不要为了覆盖研究地图而接入全部模型。

| 风险 | 第一版应具备的处理 | 不必立即增加的内容 |
|---|---|---|
| 美观掩盖真实损伤 | 无关改善对照训练和压力测试 | 多个审美模型投票 |
| 对象位置或对齐错误 | 对应区域核查与无法确认状态 | 通用三维重建 |
| 小文字无法识别 | 局部放大 OCR 与可读性状态 | 自研 OCR 模型 |
| 合理关联变化被误罚 | 有人工共识的专项样例及指令条件检查 | 全物理世界模拟器 |
| 检查工具失效或矛盾 | 缺失值区别于正常结果 失败日志 拒判或后备检查 | 冗余调用所有工具 |
| 合成痕迹被模型利用 | 真实编辑测试 留出构造方式 | 无限增加合成数据 |
| 未见编辑器失效 | 按编辑器划分的测试 置信校准 | 同时训练所有编辑器 |

能力纳入规则：只有当它解决已观察到的故障，或是检验主假设的必要对照，才优先加入。新增组件应有消融实验；没有增益或成本不合算，可以移除。不得只报告成功子集。

## 六 我的贡献与团队边界

### 需要由我承担并能形成贡献的工作

1. 定义可检验诊断的表示、标签与评价协议，说明为什么传统标量评分不足以检验这些行为。
2. 构造并审核对照数据，保留真实编辑数据、人工分歧及干预有效性记录。
3. 提出并实现诊断响应学习与证据价值学习的具体机制，和强基线比较。
4. 完成真实性、一致性、泛化、工具故障和等预算实验，分析成功与失败条件。
5. 提供小组可调用的诊断接口，并验证其对决策的增量价值。

接入现有模型、写 JSON、换提示词、实现数据加载等是必要工程工作，但不能单独充当主要科学创新。反过来，复用骨干不削弱贡献：若新的学习问题与方法产生可信、可归因的改善，就有独立研究价值。

| 预测与决策队友 | 动作收益及代价预测 预算下动作选择 | 接收诊断状态 输出编辑动作 |

接口至少含 sample_id、instruction、diagnoses、evidence、uncertainty、inspection_cost、schema_version。未知与正常必须分开编码。第一版不要求复杂自由文本反馈才能被决策器消费。

你选择“看哪里、检查什么”，队友选择“怎么改图”。若你开始学习每个编辑动作的收益并直接选动作，就进入队友研究边界，需要协商。原方案的控制动作从原图执行，不应自动解释为对当前结果的顺序修复；反馈闭环需要单独适配，不能声称原系统已经支持。

独立研究可直接使用公开编辑结果或固定工具生成结果；最终联合实验才依赖团队接口。模型输出若用于队友训练标签，最终成绩不能再只用同一模型判定，必须保留独立人工或外部评价证据。

## 七 能证明自己贡献的实验

### 核心对照

| 实验版本 | 目的 |
|---|---|
| 直接评价或现有专用评分模型 | 确定基础水平 |
| 同一骨干加固定检查清单 | 排除仅靠提示与流程的收益 |
| 同一骨干直接选择工具 | 排除通用模型已有路由能力 |
| 对照诊断训练加固定检查 | 隔离诊断学习贡献 |
| 对照诊断训练加学习的检查选择 | 隔离主动核验贡献 |
| 随机检查与全量检查 | 测试选择策略是否必要以及性能上限 |

主动策略比较须固定骨干、工具集合、信息权限和预算；专用评分模型可另作外部强基线，不冒充完全等条件消融。成本同时报告调用、耗时及必要时显存；不同检查不能只按次数视作等价。使用按原图分组的区间估计，不能把同源多个变体当完全独立样本。

### 需要报告的结果

诊断真实性与漏报误报；正确修正后的撤销率；无关变化下的错误翻转；新损伤检出；证据区域与要求是否对应；不确定性风险覆盖曲线；准确性成本曲线；未见编辑器表现；最终编辑成功与新损伤。不能只优化自己定义的一致性指标。

### 数据隔离

在构造变体前按原图划分训练开发测试，同一原图所有变体归同一集合。最终封存测试不得进入提示调整、策略选择或标签校准。教师模型伪标签用于训练必须注明来源，不能同时作为独立真值。真实结果与人工构造结果分开报告。

## 八 资源计划与阶段判断

已知条件：每周 8–15 小时，一位同学能帮助标注，算力和 API 经费未知。不能假定学校实验室一定提供某型号 GPU。建议先确认可用显存、预约方式与预算，再决定骨干部署。GPU 不足可先做缓存特征或按批次调用，成本仍计入。

首轮标注可从 20 组试标测时，再决定扩到约 200 组训练开发和 100 组独立测试。此前估计的约 30–60 合计人时只是首轮标签工作的规划值，不保证足够训练；主动检查轨迹和关联变化判断可能增加工作量。数据生成、工具开发、仲裁与小组原计划盲评另计。你本人预留约 40–60 小时标注相关工作只能作预算占位，需以试标修正。

| 阶段 | 主要产物 | 继续或调整的依据 |
|---|---|---|
| 约第 1–2 周 | 失败案例 20 组试标 强基线初测 | 人类是否有共识 是否存在值得研究的基线错误 |
| 约第 3–6 周 | 固定工具与诊断训练首版 | 真实开发集有无收益 是否只识别合成痕迹 |
| 约第 7–10 周 | 证据收益记录与轻量选择器 | 相比固定清单是否存在等预算收益 |
| 后续约第 11–16 周及以上 | 泛化 压力测试 独立测试 小组对接 | 置信区间与误差分析是否支持主张 |

这是时间安排示例，不是工期承诺；约 16 周按每周 8–15 小时为 128–240 小时，完整联合验证可能更长。学校立项所需工时和期限需另查当年通知。

若固定检查已足够好，保留诊断学习贡献，不能硬称主动选择有效。若合成收益不迁移，先修数据和表示，不盲目扩大标注。若工具质量是瓶颈，用人工可靠证据实验估计方法上限，再决定是否值得改工具。此上限实验不能作为部署性能。

## 九 和导师讨论时希望得到的判断

1. 主贡献是否应放在可检验诊断学习，主动核验作为第二贡献，还是反过来？
2. 哪两类合理变化与损伤的混淆，既有价值又能获得人类共识？
3. 最接近的方法是否已覆盖相同监督与检查机制？应优先复现哪一项？
4. 是否支持固定骨干加轻量学习路线，可提供什么算力和标注资源？
5. 独立课题与三人论文如何划分数据、代码和实验责任？

可直接口述：我希望研究能检验自己判断的图像编辑评价器。它不仅发现错误，还学习什么证据应使诊断成立或失效，并在有限预算下选择有辨别力的检查。基础感知和评分复用开源，我主要研究诊断监督和证据选择，用真实编辑结果验证，再将诊断状态接入小组决策器。目前最需要确认的是与最近工作的实质差异，以及哪组实验最能验证核心假设。
